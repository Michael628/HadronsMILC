# Autoresearch ideas — HadronsMILC

- **Fuse across color columns in StagLMAMesonFieldProp** (extends the committed `422c7aa` fusion): the three color columns' accumulators are all linear combinations of the SAME eigenvectors — one `accelerator_for` pass per eigenpair could update all 3 SUM + 3 DIFF accumulators (6 rb fields), cutting eigenvector traffic from 6 streams/eigenpair (original) to 1. Needs 6 hoisted view pairs (view-mode exclusivity caveat below) and ~2x temp memory for accumulators; arithmetic per element stays axpy-verbatim → bit-identical. Expected win grows with nEigs and volume (memory-bound).
- **Drop the redundant `rbFermNeg = Zero()` before `mat.Meooe(rbTempNeg, rbFermNeg)`** (LMAMesonFieldProp.hpp, per color column): Meooe/Dhop fully overwrites its output, so the zero-init is a wasted full-field write per column (3 per output). Verify by bit-identity harness after removal.
- **Hoist `outputName()`/`gammaList()` parsing out of the output loops**: `gammaList()` re-parses the gammas string (with O(n²) duplicate check) on every `outputName()` call — called ~2× per output in execute() plus per-output in setup(). Effect likely sub-noise on 4^4 but grows with output count; also pure code hygiene (single computed name family per execute).
- **Grid view-family exclusivity (lesson for any future custom kernels)**: a buffer's Accelerator-mode views (`autoView(..., AcceleratorRead/Write)`) must ALL close before any CPU-mode view opens on it — `setCheckerboard`, reductions, and some transfer ops use CPU-mode views, and `MemoryManagerCache.cc` asserts (`AccCache.accLock==0`). Scope hoisted views tightly; this crashed the first version of `422c7aa`.
- **Harness pitfall**: Hadrons output "directories" (`file.20/`, `ref.20/`) collide when copying multiple schedules into one dir — keep per-schedule subdirs when snapshotting for bit-identity gates. The two schedules' `ref.20` datasets legitimately differ from each other.
- **Measurement noise on this box is heavy** (module-time reps varied 18.9→28.7 ms within one arm): use min-of-3+ per arm; prefer the module's own timer from the Hadrons end-of-run table over wall-clock.

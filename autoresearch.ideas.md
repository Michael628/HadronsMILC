## Open ideas (bench8: 4^4 real config, nEigs=60, 8 outputs — module ~7.6-8.1 ms floor)
- **Batching ladder is DONE at 8**: batch-16 measured as a regression on this build (register spill hypothesis, e9b3fea). Do not extend the ladder without GPU profiling evidence.
- **Bigger benchmark, revisited**: bench8 (4^4 real config, Nstop=60, tA..tB full, gitignored under test/work/bench8/) resolves ~4% module changes ONLY via quiet-mode floors under interleaved A/B. A true 8^4+ benchmark needs a REAL (non-free) 8^4 gauge config — free-field 8^4 IRL is pathological under Cheby(0,24) (0/60 converged, 46 min, abort). If a real 8^4 config appears, redo the harness at 8^4; the accumulator-traffic and prop-store cuts should pay MORE on larger volumes.
- **Remaining per-output kernels (12 @60 eigs)**: 8 eigenpass + 3 Meooe + 1 assembly. The eigenpass is batching-limited (see above); Meooe is API-blocked (single-field stencil); the assembly is already single-pass. Next structural step would need a different decomposition (e.g. eigenpass fusing the assembly's scale into coefficients — arithmetic-order change, breaks bit-identity; needs value-gate decision).
- **MILC tensor nesting lesson**: FermionField = iScalar<iScalar<iVector<Complex,3>>>, PropagatorField = iScalar<iScalar<iMatrix<Complex,3>>> — component access in accelerator code is v()()(a) / pmat()()(a,c) (double iScalar unwrap). Lattice::vector_type is the RAW SIMD type, NOT the site object — for a fresh site object use auto x = coalescedRead(view[ss]) as the value-type carrier. Dependent-type declarations in template bodies need typename.

- **Grid view-family exclusivity (lesson for custom kernels)**: a buffer's Accelerator-mode views must ALL close before any CPU-mode view (setCheckerboard, reductions, transfers) opens on it — `MemoryManagerCache.cc` asserts. Scope hoisted views tightly.
- **autoView macro pitfall**: `autoView(n, *ptr[i], mode)` expands to `*ptr[i].View(mode)` — `.` binds tighter than `*`; bind a named reference first (hit again in 86307b1's sumR view).
- **Harness pitfalls**: Hadrons output directories (`file.20/`, `ref.20/`) collide across schedules — snapshot per-schedule subdirs; the two schedules' `ref.20` datasets legitimately differ. Box noise is HEAVY and BIMODAL (quiet mode vs contended 13-29 ms): pairwise A/B wins carry signal only at 9+/12 margins; the discriminant is the per-arm quiet-mode floor (min + floor-cluster mean) over interleaved pairs — single-arm batches once inverted a verdict. /tmp is wiped between turns — keep scratch harnesses inside the repo (gitignored test/work/…). Bit-identity gate protocol: snapshot witness HDF5 dataset sha256s (multigamma g1/g5/conj/ref + file-compare file/ref) before the change, compare after. accelerator_for captures are safe for value-captured `const bool` flags on both CPU (synchronous thread_for) and CUDA ([=]) paths. Generated-kernel protocol: emit big unrolled statement blocks (batch-8's 54) with python, never by hand.
